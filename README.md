# 暖账 0.4.0 · 多计划独立记账

支出页选择计入计划后，可选择具体计划；选计划外不扣任何计划。收入选择记入哪个计划补回额度；不加入只增账户资金。转账可关联计划留痕，不增减预算。固定开支依其所属计划扣款。日期重叠不再让一笔支出扣多个计划。

计划可花余额按独立预算、所选收支及本计划预留计算，不再被其他计划的消费或共享账户余额连带扣减；超支显示负数。真实账户实存及个人可用另行显示，不代表多个计划有多份真实资金。首页可切换显示执行中计划。

旧流水升级时一次性固定归属：收入沿用原补回计划，固定开支沿用所属计划，其他旧支出按日期匹配跨度最大计划（相同跨度按ID稳定选一项）；原计划外保留。历史收支与账户总额不变，重叠计划历史报表会消除重复。写入schema5，读取schema1至5。新建账目保留计划ID与名称，删除计划不把其流水自动转入其他计划。

新仓库首次构建：将解压后的全部文件（包含.github）放仓库根目录，Actions → Build Android APK → Run workflow，默认first_build勾选。下载warm-ledger-0.4.0-apk及签名备份。更新前导出完整账本备份。新签名无法覆盖旧签名时，请勿在无备份时卸载。

本地静态分析、Flutter测试和模型回归结果见VALIDATION.md。未执行云端APK构建或安卓真机验收。
